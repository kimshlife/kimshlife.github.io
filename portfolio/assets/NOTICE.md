# Logo and font sources

Technology icons are from Devicon v2.16.0, downloaded as SVG files from the published repository via jsDelivr.

Repository: https://github.com/devicons/devicon/tree/v2.16.0

- python: icons/python/python-original.svg
- react: icons/react/react-original.svg
- vue: icons/vuejs/vuejs-original.svg
- unity: icons/unity/unity-original.svg
- jira: icons/jira/jira-original.svg
- git: icons/git/git-original.svg
- typescript: icons/typescript/typescript-original.svg
- figma: icons/figma/figma-original.svg

These logos identify tools used in the portfolio; they do not imply affiliation or endorsement. The P/X/W letter markers are plain typographic labels, not reproduced Microsoft logos. Line icons in script.js are simple original SVG paths.

License: https://github.com/devicons/devicon/blob/v2.16.0/LICENSE

https://github.com/orioncactus/pretendard/tree/v1.3.9
Font file: packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2
Its SIL Open Font License is included in pretendard-LICENSE.txt.
