PEAK → SSketch설정 레퍼런스 해석·빌드 결함 분석

골격은 가져오고, 없는 기능은 제외하다.

1인칭 등반 게임의 설정을 3인칭 드로잉 게임에 대조하고, 빌드에서만 발생한 결함의 원인을 추적했습니다.

2026.09SSketch / 설정 분석·구현
01

기능 이름보다 게임의 조건을 비교했습니다.

PEAK는 1인칭 등반, SSketch는 3인칭 드로잉 게임입니다. 탭·항목·설명의 골격과 미저장 경고는 가져오되, 시야각과 홀드·토글은 현재 게임의 조작에 맞춰 바꿨습니다. 없는 기능의 선택지를 먼저 만들지 않도록 했습니다.

02

취향 설정과 게임 규칙의 경계를 뒀습니다.

OS 마우스 가속을 실제로 끌 수 없는 스위치와 당장 쓰지 않는 DLSS는 제외했습니다. 스테디 펜의 따라오기 속도는 낮출수록 그림을 쉽게 그리게 하므로 사용자 취향이 아니라 밸런스 값으로 보고 설정에 넣지 않았습니다.

03

에디터에서 정상이어도 빌드를 다시 확인했습니다.

빌드에서 해상도를 낮춘 뒤 복구하지 못하는 문제, 키 재설정이 조용히 버려지는 문제, 수직동기화가 덮어써지는 문제를 추적했습니다. 원인은 각각 현재 해상도를 상한으로 삼는 조건, 실제와 다른 키 이름을 찾는 검사, 품질 레벨의 적용 순서였습니다.

02SSketch에만 필요한 것
  • 밤 밝기 — 밤의 어둠은 연출이 아니라 규칙입니다. 밝기를 무제한으로 올리면 익명성이 무너집니다.
  • 스테디 펜 속도는 설정에 넣지 않음 — 낮출수록 선이 매끄러워져 실력 차이를 지웁니다. 취향이 아니라 난이도입니다.
  • 보이스 채팅 — 입력 음소거 · 입출력 볼륨 · 마이크 장치 선택

최종 구현에서는 스위치를 ‘끔/켬’ 두 버튼으로 바꾸고, 주사율 · Y축 반전 · 밝기를 뺐으며, 화면 되돌림 확인 창은 해상도와 화면 모드를 바꿀 때만 뜨게 했습니다.
